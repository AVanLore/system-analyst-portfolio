| Пункт | Содержание |
|---|---|
| **Идентификатор** | US-CLNT01 |
| **Заголовок** | Возможность записываться онлайн |
| **US** | Как клиент, я хочу записываться на услугу онлайн, чтобы процесс не занимал много времени |
| **Ценность** | Быстрая запись без необходимости звонить менеджеру |
| **Требуемые действия** | Зайти на сайт; выбрать подходящую услугу; выбрать мастера; выбрать удобное время; отправить заявку |
| **Критерии приемки (Given-When-Then)** | • **Given:** Клиент заходит на сайт барбершопа<br>• **When:** Клиент выбирает услугу, мастера и удобное время для записи<br>• **Then:** Клиент получает уведомление о том, что заявка принята. В случае окончательного подтверждения или отклонения менеджером клиент получит дополнительное уведомление. |

| Пункт | Содержание |
|---|---|
| **Идентификатор** | US-CLNT02 |
| **Заголовок** | Получать напоминания о записи на выбранный канал связи |
| **US** | Как клиент, я хочу получать напоминания, чтобы не пропускать запись на услугу |
| **Ценность** | Предотвращение случаев, когда клиент забывает о записи |
| **Требуемые действия** | Выбрать канал связи; получить уведомление |
| **Тестовый сценарий** | • **Предусловия:** Менеджер подтвердил запись; клиент выбрал канал связи при регистрации или при записи<br>• **Действия:** Клиенту отправляются уведомления только по подтвержденной записи на выбранный канал связи: за день / за час до записи<br>• **Ожидаемый результат:** Клиент не забывает о записи на услугу |
