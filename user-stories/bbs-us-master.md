| Пункт | Содержание |
|---|---|
| **Идентификатор** | US-MSTR01 |
| **Заголовок** | Просматривать свое расписание записей |
| **US** | Как мастер, я хочу просматривать свое расписание, чтобы составить свой график на неделю и чтобы не пропустить любые изменения в расписании |
| **Ценность** | Удобство работы для мастеров; возможность прослеживать выполненную работу мастеров |
| **Требуемые действия** | Открыть сайт барбершопа; перейти в личный кабинет сотрудника; зайти на страницу с календарем; посмотреть запись на ближайшие дни / недели |
| **Критерии приемки (Given-When-Then)** | • **Given:** Мастер авторизован в системе и имеет доступ к своему расписанию.<br>• **When:** Мастер открывает страницу расписания.<br>• **Then:** Система отображает актуальные записи и слоты на выбранный период (день/неделя). |
