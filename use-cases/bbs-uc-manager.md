| Пункт | Содержание |
|---|---|
| **Идентификатор UC** | UC-BBS01 |
| **Название UC** | Поддержка актуального расписания |
| **Основное действующее лицо (Actor)** | Менеджер |
| **Другие заинтересованные стороны и их интересы** | Мастер — просмотр расписания записей<br>Клиент — просмотр расписания мастеров<br>Руководитель — расширение клиентской базы за счет увеличения числа записей |
| **Цель (назначение) UC** | Обеспечить актуальность расписания услуг мастеров, чтобы клиенты могли видеть доступное время для записи, а мастера — свои рабочие интервалы |
| **Предусловия** | Менеджер имеет доступ к управлению расписанием |
| **Триггер** | Менеджер инициирует управление расписанием |
| **Постусловия (гарантии)** | **Минимальные гарантии:**<br>• Система сообщает менеджеру, если изменения не сохранены<br>• Данные не изменяются при ошибке<br><br>**Гарантии успеха:**<br>• Новое расписание мастеров сохранено в системе<br>• Обновленные данные доступны для просмотра мастерами и клиентами<br>• Изменения доступны мастерам и клиентам при записи и просмотре расписания |
| **Предположение** | Все данные вводятся вручную силами менеджера<br>Все сотрудники имеют доступ к системе<br>Все виды услуг занесены в систему |

**Поток событий UC-BBS01**

| Шаг | Описание |
|---|---|
| 1 | Менеджер начинает управление расписанием |
| &nbsp;&nbsp;&nbsp;&nbsp;1а1 | Система сообщает об ошибке |
| &nbsp;&nbsp;&nbsp;&nbsp;1а2 | Менеджер повторяет попытку начать управление расписанием (п.1) или завершает UC |
| 2 | Менеджер просматривает текущее расписание и выбирает нужного мастера или услугу |
| 3 | Менеджер вносит изменения: добавляет новые слоты, корректирует или удаляет существующие |
| &nbsp;&nbsp;&nbsp;&nbsp;3а1 | Менеджер отменяет изменения и завершает редактирование или прекращает работу с расписанием |
| 4 | Система фиксирует изменения |
| &nbsp;&nbsp;&nbsp;&nbsp;4а1 | Система сообщает об ошибке |
| &nbsp;&nbsp;&nbsp;&nbsp;4а2 | Менеджер повторяет попытку сохранить изменения (п.4) или завершает UC |
| 5 | Система подтверждает успешное сохранение |
