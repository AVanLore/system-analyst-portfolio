| Пункт | Содержание |
|---|---|
| **Идентификатор UC** | UC-BBS03 |
| **Название UC** | Просмотр актуального расписания мастером |
| **Связи с другими UC** | **Extend:** UC-BBS03-1 "Просмотр отзывов клиента" — мастер просматривает обратную связь клиентов |
| **Основное действующее лицо (Actor)** | Мастер |
| **Другие заинтересованные стороны и их интересы** | Менеджер — контроль количества работы сотрудников<br>Клиент — обслуживание в назначенное время<br>Руководитель — расширение клиентской базы за счет увеличения числа записей |
| **Цель (назначение) UC** | Получить актуальную информацию о предстоящих записях, чтобы планировать рабочий день |
| **Предусловия** | Мастер имеет доступ к своему расписанию<br>Менеджер внес расписание мастера в систему<br>Расписание содержит актуальные записи |
| **Триггер** | Мастер запрашивает свое расписание |
| **Постусловия (гарантии)** | **Минимальные гарантии:**<br>• Система уведомляет мастера об ошибке при попытке посмотреть расписание<br>• Система не теряет данные при возникновении ошибок<br><br>**Гарантии успеха:**<br>• Мастер видит список предстоящих записей с указанием времени, клиента и услуги |
| **Предположение** | Мастер уже зарегистрирован в системе<br>Менеджер уже внес расписание мастера |

| Пункт | Содержание |
|---|---|
| **Идентификатор UC** | UC-BBS03-1 |
| **Название UC** | Просмотр отзывов клиента |
| **Основное действующее лицо (Actor)** | Мастер |
| **Другие заинтересованные стороны и их интересы** | Менеджер — контроль качества работы сотрудников<br>Клиент — оценить качество услуги<br>Руководитель — расширение клиентской базы за счет увеличения числа записей |
| **Цель (назначение) UC** | Оценить качество своей работы на основе обратной связи клиентов |
| **Предусловия** | Мастер имеет доступ к отзывам<br>У клиентов есть возможность оставить отзыв за оказанную услугу |
| **Триггер** | Мастер запрашивает отзывы |
| **Постусловия (гарантии)** | **Минимальные гарантии:**<br>• Система уведомляет мастера об ошибке при попытке получить отзывы<br>• Система не теряет данные при возникновении ошибок<br><br>**Гарантии успеха:**<br>• Мастер видит список отзывов с оценками и комментариями по каждой оказанной услуге |
| **Предположение** | Мастер уже зарегистрирован в системе |
