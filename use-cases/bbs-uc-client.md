| Пункт | Содержание |
|---|---|
| **Идентификатор UC** | UC-BBS02 |
| **Название UC** | Выбор услуг мастеров и бронирования выбранных слотов |
| **Связи с другими UC** | **Include:** UC-BBS02-1 «Выбрать услугу» — клиент выбирает услугу из каталога<br>**Include:** UC-BBS02-2 «Выбрать мастера» — клиент выбирает мастера из доступных<br>**Include:** UC-BBS02-3 «Забронировать слот» — клиент выбирает свободное время<br>**Extend:** UC-BBS02-4 «Просмотреть информацию о мастере» — клиент запрашивает подробную информацию о мастере |
| **Основное действующее лицо (Actor)** | Клиент |
| **Другие заинтересованные стороны и их интересы** | Мастер — получает поток клиентов и видит их записи<br>Менеджер — получает подтвержденную запись, может управлять расписанием<br>Руководитель — расширение клиентской базы за счет увеличения числа записей |
| **Цель (назначение) UC** | Обеспечить удобство клиентам возможностью записываться онлайн и предоставить выбор конкретного мастера для оказания услуги в определенное время |
| **Предусловия** | Клиент может воспользоваться онлайн-записью<br>В системе занесена информация об услугах, доступных мастерах и свободных слотах для записи<br>Система содержит актуальное расписание мастеров |
| **Триггер** | Клиент инициирует запись |
| **Постусловия (гарантии)** | **Минимальные гарантии:**<br>• Система уведомляет клиента об ошибке при попытке записаться<br>• Система не теряет данные при возникновении ошибок<br>• Система не создает частичную запись, если операция не завершена<br><br>**Гарантии успеха:**<br>• Система уведомляет клиента о подтверждении записи менеджером<br>• За клиентом закреплен выбранный им слот<br>• Услугу будет оказывать выбранный клиентом мастер |
| **Предположение** | Клиент уже зарегистрирован или оставил свой канал связи |

**Поток событий UC-BBS02**

| Шаг | Описание |
|---|---|
| 1 | Клиент инициирует запись |
| &nbsp;&nbsp;&nbsp;&nbsp;1а1 | Система сообщает об ошибке |
| &nbsp;&nbsp;&nbsp;&nbsp;1а2 | Клиент повторяет попытку записи (возвращается на п.1) или завершает UC |
| 2 | Клиент выбирает услугу (UC-BBS02-1) |
| &nbsp;&nbsp;&nbsp;&nbsp;2а1 | Система сообщает об ошибке |
| &nbsp;&nbsp;&nbsp;&nbsp;2а2 | Клиент повторяет попытку выбора услуги (возвращается на п.2) или завершает UC |
| 3 | Клиент выбирает мастера (UC-BBS02-2) |
| &nbsp;&nbsp;&nbsp;&nbsp;3а1 | Клиент запрашивает подробную информацию о мастере (UC-BBS02-4) |
| &nbsp;&nbsp;&nbsp;&nbsp;3а2 | Клиент возвращается к списку мастеров (возвращается на п.3) |
| 4 | Клиент бронирует слот (UC-BBS02-3) |
| &nbsp;&nbsp;&nbsp;&nbsp;4а1 | Система сообщает об ошибке |
| &nbsp;&nbsp;&nbsp;&nbsp;4а2 | Клиент повторяет попытку (возвращается на п.4) или завершает UC |
| 5 | Клиент проверяет данные и подтверждает запись |
| &nbsp;&nbsp;&nbsp;&nbsp;5а1 | Система отменяет запись |
| &nbsp;&nbsp;&nbsp;&nbsp;5а2 | UC завершается без сохранения |
