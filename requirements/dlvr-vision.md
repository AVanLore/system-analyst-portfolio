## 4. Бизнес-требования

### 4.1. Проблемы, для решения которых создается или дорабатывается система

| Кому мешает | Проблема |
|---|---|
| Курьер | 1. Не видит свой заработок.<br>2. Не знает длительность доставки.<br>3. Не может сам выбрать заказ. |
| Диспетчер | 1. Не может быстро связаться с курьером.<br>2. Ошибается при вводе данных о заказе. |
| Администратор | 1. Регистрация курьера занимает много времени.<br>2. Для отчета бухгалтерии информация проверяется вручную. |
| Оператор | 1. Ошибки при вводе информации о заказе.<br>2. Нет шаблона для ввода. |

### 4.2. Предусловия, окружение, ситуация

| Пункт | Содержание |
|---|---|
| **Предусловия** | На момент внедрения системы доставка осуществляется без единой автоматизированной системы: заказы принимаются по телефону, данные фиксируются вручную (бумажный журнал или Excel), связь с курьерами через телефонные звонки или мессенджеры, отчёты формируются вручную. |
| **Окружение** | • Курьеры имеют смартфоны (iOS/Android) с доступом в интернет.<br>• Диспетчеры, операторы и администраторы работают за стационарными ПК (Windows) с доступом в интернет. |
| **Ситуация** | Высокая нагрузка на диспетчеров, частые ошибки ввода, недовольство курьеров непрозрачной оплатой, задержки доставок из-за отсутствия оперативного переназначения. |

### 4.3. Возможности, позволяющие решить проблемы с помощью нашей системы

| Какие проблемы решает | Возможность системы |
|---|---|
| Курьер не видит заработок | Личный кабинет с начисленной оплатой, отображение заработка за доставку |
| Курьер не знает длительность | Расчет примерного времени выполнения относительно местоположения курьера |
| Курьер не может выбрать заказ | Мобильное приложение: просмотр доступных заказов, бронирование |
| Диспетчер ошибается при вводе | Подсказки при вводе (улицы, магазины), маски полей, автодополнение |
| Диспетчер не может быстро связаться | Встроенные уведомления, чат или звонок через интерфейс (при интеграции) |
| Администратор тратит много времени на регистрацию | Удобная форма с подсказками, быстрая регистрация курьера, кнопка блокировки |
| Оператор ошибается / нет шаблона | Шаблоны заказов, подсказки, горячие клавиши, обязательные поля, уведомление о доставке |
| Ручной отчет для бухгалтерии | Автоматическая выгрузка отчёта (формат [XLSX/CSV/XML]) |
| Переназначение заказов неудобно | Интерфейс диспетчера: drag-and-drop или кнопка переназначения, карта статусов курьеров |

### 4.4. Бизнес-цель(и) — основные цели, ради которых строится система

| № | Бизнес-цель |
|---|---|
| 1 | Уменьшить долю ошибочных заказов на 80% |
| 2 | Сократить среднее время доставки на 25%. |
| 3 | Повысить удовлетворенность курьеров и снизить текучесть |
| 4 | Сократить трудозатраты администратора на 90% |
| 5 | Масштабируемость – система должна поддерживать рост количества заказов без увеличения штата диспетчеров и операторов. |
